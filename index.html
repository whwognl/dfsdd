로컬 처리
보안 고객 개인정보는 외부로 전송되지 않습니다. 발주서·배송지 등 모든 데이터는 이 컴퓨터(브라우저) 안에서만 처리·저장되며 외부 서버·API로 전송되지 않습니다. 이 도구는 자동 로그인·자동 결제·매크로를 제공하지 않습니다. 실제 구매는 사용자가 직접 진행합니다.
클라우드 구글시트 연동(클라우드 모드)이 켜져 있습니다. 이 모드로 시트를 불러올 때는 발주서 데이터(고객 개인정보 포함)가 구글 클라우드를 경유합니다. 그 외의 처리는 여전히 이 PC 안에서만 이뤄집니다. 끄려면 [설정 → 구글시트 연동]에서 해제하세요.

구글시트에서 바로 붙여넣기

파일을 내려받지 않고도 됩니다. 구글시트(또는 엑셀)에서 헤더 행을 포함한 범위를 선택해 복사(Ctrl/⌘+C)한 뒤, 아래 칸에 붙여넣고 버튼을 누르세요. 붙여넣은 데이터도 외부로 전송되지 않고 이 PC 안에서만 처리됩니다.

사용 순서

  1. 쿠팡에서 발주서(엑셀)를 내려받아 위에 올립니다.
  2. 주문관리 탭의 시트에서 소싱링크를 확인하고 구매할 사이트를 엽니다.
  3. 그 사이트에서 직접 로그인·구매합니다. (도구는 구매에 관여하지 않습니다)
  4. 시트의 입력준비를 누른 뒤, 구매 사이트 오른쪽 아래에 뜨는 🚀 주문 자동입력 버튼을 누르면 이름·전화·주소가 채워져요. (크롬 확장 설치는 ⚙설정 참고) 끝나면 완료 체크 → 송장번호 입력.
  5. 다 끝나면 우측 상단 내보내기로 처리결과를 저장합니다.

열(컬럼) 확인

발주서 헤더를 자동 인식했습니다. 잘못 연결된 항목이 있으면 드롭다운에서 바꿔주세요. (* 는 필수)

쓰는 값발주서 열 선택상태
자동 저장됨 이 표가 작업 시트입니다. 완료 체크로 행 색이 바뀌고, 출고중지·반품접수를 체크하면 CS관리 탭으로 이동합니다. 엑셀·구글시트에서 복사한 표 블록을 그대로 붙여넣을 수 있고, 열 머리글 드래그로 순서와 크기를 조절합니다. Enter/↑↓로 칸 이동.

결제창 자동입력

구매 사이트(네이버·쿠팡·지마켓·옥션 등) 결제창에서 이름·전화·주소를 한 번에 채워주는 도구예요. 로그인·결제는 직접 하시고요.

자동입력용 내 연락처 (필수) — 고객 번호 대신 항상 이 번호가 들어가요. 안 넣으면 자동입력이 준비되지 않아요(고객 번호가 구매처에 노출되는 걸 막기 위해서예요).

참고: 자동입력은 해당 사이트 약관상 회색지대예요(불법은 아니지만 사이트 정책 위반 소지). 본인 판단·본인 책임으로 쓰세요. 사이트 화면이 바뀌면 칸 인식이 빗나갈 수 있으니 결제 전 반드시 확인하세요.

설치 (최초 1회 · 크롬 확장):

  1. 크롬 주소창에 chrome://extensions 입력 → 엔터
  2. 오른쪽 위 개발자 모드 켜기
  3. 압축해제된 확장 프로그램을 로드합니다 클릭 → order-helper/naver-autofill-extension 폴더 선택
  4. ※ 확장 코드가 업데이트되면 chrome://extensions에서 ↻ 새로고침을 눌러야 반영돼요

쓰는 법: ① 주문관리 시트에서 입력준비 클릭 → ② 구매 사이트 주소입력 화면 오른쪽 아래에 뜨는 🚀 주문 자동입력 클릭 → 이름·전화 입력 + 주소검색 자동 실행 → ③ 주소 선택하면 상세주소까지 자동 → ④ 확인 후 직접 결제.

간이 자동입력(구형)

구글시트 실시간 연동 (클라우드 모드 · 선택)

주의 이 모드를 켜면 시트를 불러올 때 고객 개인정보가 구글 클라우드를 경유합니다(이 도구의 기본 원칙인 "100% 로컬"에서 벗어남). 또한 구글 OAuth Client ID가 필요하고, localhost 로컬 서버에서 실행해야 합니다(파일 더블클릭 file:// 에서는 작동하지 않음). 설정 방법은 README 참고.

① 구글 OAuth Client ID (Google Cloud Console → 사용자 인증 정보 → OAuth 클라이언트 ID, 웹 애플리케이션)

② 비공개 구글시트 주소 또는 시트 ID

③ 범위 (선택 — 비우면 첫 번째 시트 전체). 예: 발주서!A:Z

현재 실행 주소: — 이 주소를 OAuth 클라이언트의 승인된 JavaScript 출처에 등록하세요.
