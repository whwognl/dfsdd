# 우루루 통합 주문관리

2026-09 최신 주문서 양식(53열)을 기준으로 만든 **주문처리 반자동화 도구**입니다.
같은 데이터로 두 가지를 만듭니다.

| 결과물 | 무엇 | 어떻게 |
|---|---|---|
| **웹앱** | 브라우저에서 쓰는 통합 관리 화면 | `index.html` 실행 |
| **엑셀 양식** | 수기로도 쓸 수 있는 자동계산 워크북 | 앱의 **[엑셀 양식 내려받기]** 또는 `node tools/build-template.js` |

두 결과물은 열 이름·순서·계산식이 완전히 같습니다. 엑셀로 작업하다 앱으로 올려도,
앱에서 뽑아 엑셀로 이어 작업해도 그대로 이어집니다.

---

## 1. 실행

빌드도 설치도 필요 없습니다.

```bash
cd <이 폴더>
python3 -m http.server 8777
# 브라우저에서 http://localhost:8777
```

`index.html`을 더블클릭해도 대부분 동작하지만, 로컬 서버로 여는 쪽을 권합니다.

## 2. 하루 흐름

1. **파일 불러오기** — 쓰던 워크북(.xlsx)을 그대로 올립니다.
   주문서 · 블랙리스트 · 수수료 · CS · 사입 · 계정카드정보 · 송장업로드리스트 · DAY/MON을 한 번에 읽습니다.
2. **대시보드** — 오늘/이번달 매출·순마진·마진률, 발주 대기, 송장 대기, 위험 건수를 확인합니다.
3. **주문관리** — 한 행마다 두 번의 딸깍으로 끝냅니다.
   - `준비 ↗` : 배송지·수령자 정보를 **내 번호로 바꿔** 복사하고 구매링크를 새 탭으로 엽니다.
   - `발주` : 주문여부 O · 결제일시 · 담당자/구매처/계정/카드를 한 번에 기록합니다.
   - 여러 건을 체크한 뒤 **[일괄 입력]** 으로 구매처·구매금액·카테고리를 한 번에 채웁니다.
4. **송장** — 송장 붙여넣기 → EMP 출고목록 대조 → 쿠팡 송장 업로드 파일 생성.
5. **블랙리스트** — 수령자명·주소가 걸리면 주문관리 행이 **빨간색 "위험"** 으로 뜹니다.

자동화할 수 없는 부분(로그인·결제·상품 선택)은 그대로 사람이 합니다.
이 도구는 **정리·계산·확인**만 대신합니다.

## 3. 계산식 (워크북과 동일)

```
수수료율(VAT) = 수수료율 x 1.1
결제기준가    = 판매가 x (1 - 수수료율VAT)
배송비순액    = 배송비 x (1 - 수수료율VAT)
순마진        = (결제기준가 + 배송비순액 - 구매금액 - 에누리) / 1.1
부가세        = 순마진 x 10%
마진률        = 순마진 / 판매가
올라수수료    = 판매가 x 0.96%   (설정에서 변경 가능)
```

수수료율은 **카테고리**로 찾습니다. 카테고리가 비어 있으면 상품명으로 추정합니다.
구매금액이나 수수료율이 없으면 순마진을 억지로 만들지 않고 `—` 로 둡니다
(대시보드의 "계산 대기" 건수가 그것입니다).

## 4. 블랙리스트 판정 기준

| 상황 | 표시 |
|---|---|
| 이름 + 주소가 모두 일치 | **위험** (빨간 행) |
| 연락처 뒷 8자리 일치 | **위험** |
| 주소 없이 이름만 등록된 사람과 이름 일치 | **위험** |
| 이름만 일치 / 주소만 일치 | 주의 (노란 행) |

- 마스킹 이름(`김성*`)은 한 글자 와일드카드로 인식하되, 주소까지 맞아야 경고합니다.
- 주소는 **번지·동·호수 숫자가 전부 맞아야** 일치로 봅니다.
  "경기도 용인시 기흥구"처럼 행정구역만 겹치는 것은 일치로 보지 않습니다.

## 5. 개인정보 · 보안

- 모든 처리와 저장은 **이 브라우저 안에서만** 이뤄집니다. 외부 서버·API 호출이 없습니다.
- 자동 로그인 · 자동 결제 · 매크로는 만들지 않습니다.
- `준비 ↗` 로 복사되는 연락처는 설정의 **내 번호**입니다. 고객 번호가 구매처로 넘어가지 않습니다.
  (내 번호를 안 넣으면 고객 번호가 복사되니 반드시 설정하세요.)
- **계정·카드 정보는 백업 파일과 엑셀 내보내기에 들어가지 않습니다.** 화면에서도 기본은 가려져 있습니다.
- 데이터는 브라우저 저장소에만 있습니다. 캐시를 지우거나 PC를 바꾸기 전에 **설정 → 백업 내려받기**.

## 6. 파일 구성

```
index.html      화면 + 디자인 토큰(단일 <style>)
app.js          상태 · 저장 · 대시보드 · 가져오기/내보내기 · 설정
views.js        주문관리 시트 · CS · 블랙리스트 · 송장 · 사입 · 수수료 · 계정카드
core.js         열 정의(53열) · 수수료 조회 · 마진 계산 · 블랙리스트 판정   ← 기준 파일
import.js       워크북/붙여넣기 → 표준 모델
template.js     수기용 엑셀 양식 생성(수식·드롭다운·조건부서식)
xlsx-lite.js    의존성 없는 xlsx 읽기/쓰기 엔진 (외부 라이브러리 0개)
tools/          build-template.js(엑셀 생성) · test.js(회귀 테스트) · smoke.js(브라우저 점검)
```

`core.js`가 **열 이름·순서·계산식의 단일 기준**입니다. 양식이 또 바뀌면 여기부터 고치면
앱과 엑셀 양식이 함께 따라옵니다.

## 7. 개발자용

```bash
node tools/test.js  <원본워크북.xlsx>      # 회귀 테스트 (52개 검사)
node tools/build-template.js <원본.xlsx> <출력.xlsx>   # 엑셀 양식 생성
node tools/build-template.js --blank                   # 빈 양식만
npm i && node tools/smoke.js <원본.xlsx>   # 브라우저 스모크 테스트(playwright)
```
