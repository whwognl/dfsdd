# order-helper — 반자동 주문 보조 도구 (+ 자동화 관제 데모)

쿠팡 무재고 위탁판매 셀러를 위한 **정적 HTML/JS 앱**입니다. 설치·빌드·서버 없이 브라우저 안에서만 돌아갑니다.
개발이 중단됐던 구버전 앱의 구조(탭·CS관리·시트·매입처DB 등)를 그대로 두고, 바뀐 **주문 수집 파일(36열 .xls) 양식**을 받아들이도록 고쳤습니다.

## 1. 실행

```bash
cd <이 폴더>
python3 -m http.server 8777      # 또는 npm run serve
# 브라우저에서 http://localhost:8777
```

`index.html` 을 더블클릭해도 열리지만 로컬 서버로 여는 쪽을 권합니다. 외부 라이브러리·CDN 을 쓰지 않습니다.

## 2. 하루 흐름

1. **주문 수집 파일 올리기** — 수집 프로그램이 주는 36열 `.xls`(구형 엑셀)·`.xlsx`·`.csv` 를 그대로 올립니다. 열 이름·순서를 자동으로 알아봅니다(옛 쿠팡 발주서도 됩니다).
   같은 파일을 다시 올리면 **주문고유번호** 기준으로 기존 주문에 합쳐집니다(진행상태 유지).
2. **주문관리** — 시트에서 한 행씩 처리합니다.
   - 행을 고르면 위에 **한 줄 복사 툴바**가 뜹니다: 이름 · 전화(설정의 **내 번호**) · 우편번호 · 기본주소 · 상세주소 · 배송메시지 · 전체 · [입력준비]. `순차` 를 켜면 버튼 하나로 다음 조각이 차례로 복사됩니다.
   - 완료 체크 → 구매완료, 택배사·송장번호 입력 → 송장완료.
   - 블랙리스트와 이름·주소·연락처가 겹치면 행이 **빨간색(위험)** 으로 표시되고 업로드 직후 경고 창이 뜹니다.
3. **CS관리** — 출고중지·반품 체크 또는 툴바에서 CS 를 열면 유형별 **단계 체크리스트**, 기다리는 대상(내 차례/고객/구매처/택배/쿠팡), **금액 장부**(반품비·차액 → 순마진에 자동 반영), 회수 송장, 구매처 접수, 다음 조치일, 멘트 복사, 타임라인 메모가 한 카드에 있습니다. 탭은 **오늘 할 일 / 기다리는 중 / 종결** 로 나뉩니다.
4. **송장 파일** — 상단 [송장 파일] 또는 내보내기 → **소스 양식(36열)** 으로 `.xls / .xlsx / .csv` 를 만듭니다. 배송사명은 T코드(CJ T025 · 한진 T081 · 롯데 T082 · 로젠 T030 · 업직 T048 · 천일 T069)로 나가고, 출고중지·반품·취소 건은 송장 칸이 비워집니다.
5. **대시보드** — 오늘 할 일(숫자를 누르면 그 화면으로), 기간별(오늘·어제·이번 달·지난 달) 매출·순마진·마진율, 월별·최근 14일 표.

## 3. 자동화 관제 데모 (오토파일럿)

상단 **[자동화 데모]** 를 누르면 "모든 것이 자동으로 돌아가는 모습"을 보여주는 관제 화면이 열립니다. `index.html?demo=1&speed=60` 으로 바로 켤 수도 있습니다.

- **연매출 80억 원 페이스**로 주문이 흘러갑니다: 수집 → 검수(블랙리스트·마스킹) → 발주 → 송장 → 발송 → 배송완료. CS 는 AI 응대 멘트와 함께 단계가 자동으로 진행되고, 매입처DB·라인업·블랙리스트·일별 마감·백업이 자동으로 갱신됩니다.
- 속도 1× / 60× / 600×, 일시정지, **발표 모드**(상단 메뉴를 숨기고 관제만 크게, Esc 로 해제).
- 데모가 켜진 동안 다른 탭(주문관리·CS관리·대시보드·일별매출…)도 같은 시뮬레이션 데이터로 살아 움직입니다.
- **실제 데이터는 스냅샷으로 보관되고 저장이 막힙니다.** [데모 종료] 또는 [처음으로] 를 누르면 원래 데이터로 돌아옵니다.
- 데이터 패턴(상품·가격·구매처·택배사·지역·시간대·CS 비율)은 실제 운영 워크북에서 **개인정보를 제외하고** 뽑은 `demo-data.js` 입니다(`python3 tools/make-demo-data.py <워크북.xlsx>`). 이름·전화·주소는 전부 합성·마스킹입니다.
- 실제 계정·구매처·택배사·쿠팡 어디에도 연결하지 않는 시뮬레이션입니다(화면에 "시뮬레이션 · 합성 데이터" 표시).

## 4. 계산식

```
정산 예상   = (판매가 + 배송비) × (1 − 수수료율 × 1.1)
매입        = 구매금액(있으면) 또는 구매가 × 수량 + 배송비
순마진      = (정산 예상 − 매입 − 에누리 − CS 차감) ÷ 1.1   (설정 'VAT 포함' 이 꺼져 있으면 ÷ 1.1 없음)
마진율      = 순마진 ÷ 판매가
```

수수료율은 설정의 카테고리·키워드 표로 정합니다. 매입가가 없으면 순마진을 만들지 않고 `—` 로 둡니다.

## 5. 파일

| 파일 | 역할 |
|---|---|
| `index.html`, `app.js` | 앱 본체(구버전 구조 유지) |
| `xlsx-lite.js`, `biff.js`, `xlsx-compat.js` | `.xlsx` 읽기/쓰기, `.xls`(BIFF8) 읽기/쓰기, SheetJS 호환 층 |
| `blacklist.js`, `copy-helpers.js`, `rules.js` | 블랙리스트 판정 · 주소 분리/전화 형식 · 기본 수수료 규칙 |
| `demo.js`, `demo-data.js` | 자동화 관제 데모 엔진·화면, 패턴 데이터 |
| `sample/` | 합성 샘플(36열 xlsx/xls/csv, 빈 양식) |
| `tools/` | `smoke.js`(Playwright 전체 흐름) · `demo-smoke.js` · `verify-export.js` · `test-biff.js` · `test-copy.js` · `make-demo-data.py` · `make-source-sample.py` |
| `docs/design/` | 분석·설계 보고서, 관제 화면 목업 |

```bash
npm install                # playwright 만 받습니다(테스트용)
npm test                   # 36열 내보내기 검증
npm run test:biff          # .xls 엔진 54항목
node tools/test-copy.js    # 주소 분리·전화·페이로드
node tools/smoke.js sample/소스샘플_36열.xls     # 업로드→시트→CS→내보내기 전체 흐름
node tools/demo-smoke.js 25 600                   # 데모 25초·600배속
```

## 6. 보안 원칙

- 100% 로컬 처리. 자동 로그인·자동 결제·매크로 없음.
- 자동입력 전화번호는 고객 번호가 아니라 **설정의 내 번호**만 씁니다(비어 있으면 차단).
- 계정·카드 정보는 어떤 내보내기에도 들어가지 않습니다. CSV/엑셀 수식 주입을 막습니다.
- 고객 개인정보(블랙리스트 명단·주문 데이터)는 저장소에 넣지 않습니다. 샘플은 전부 합성입니다.
